# My AwesomeWM setup.

After I've finished ricing my Cinnamon desktop, I decided to install a "window manager" called Awesome. According to many sources, Awesome is very beginner-friendly and flexible. So I decided to give it a try.

At first it wasn't impressive, all you got is a menu, a taskbar (awesome calls it Wibar), and more. So since I don't like the default look, I searched everywhere on how to customize the window manager. Luckily there's tons on YouTube, but there's also guides on the official AwesomeWM website. After customizing the thing for 3 days, this is what I came up with.

Now that's over, I'll list all the things you need:

## Programs

- awesome
- nitrogen
- lxappearance
- rofi
- compton (or picom)

## Where to put .config files?

Put the picom.conf at your documents folder, the config.rasi and nord.rasi files should be at ~/.config/rofi, and the rc.lua and theme.lua files should be in ~/.config/awesome

## Theme & Icon

- Nordic-Darker
- ePapirus-Dark

## Widgets

For widgets, head over to awesomewm.org website and click recipes. You may wanna install Lain Widgets and Awesome-WM-Widgets.

(I don't know why you need 2 widgets lol. I made this a long time ago, btw.)

## Browser

Oh and just a heads up, I used falkon as my browser, so if you encounter any errors, edit the rc.lua and search for a comment named Falkon and change it to your browser.
